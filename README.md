# Portfólio · Maryanna Conceição Silva

Portfólio pessoal de Cientista de Dados, com foco em inferência causal, machine learning e MLOps.

**Site:** https://maryannasilva.github.io/react-portfolio-mary

Feito com React, TypeScript, SCSS e Material UI. Tem tema claro e escuro e layout responsivo.

## Rodando localmente

Pré-requisito: [Node.js](https://nodejs.org/) 18 ou superior.

```bash
npm install
npm start        # servidor de desenvolvimento em http://localhost:3000
npm test         # testes
npm run build    # build de produção em build/
```

## Deploy

O site é publicado no GitHub Pages pelo pacote `gh-pages`:

```bash
npm run deploy
```

O comando gera o build e envia a pasta `build/` para o branch `gh-pages`. O endereço publicado é definido no campo `homepage` do `package.json`.
